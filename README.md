# Job Application Tracker

## Overview
A command line application for tracking job applications that are stored persistently in a JSON file


## Features
- Add job applications
- View saved applications
- View applications with interview status
- Filter applications by company
- Validate application status
- Persist application data using JSON
- Handle invalid JSON files

## How to Run
git clone https://github.com/bkgeorgo/job-application-tracker.git
cd job-application-tracker
python tracker.py

## Testing
test_tracker.py is used to verify integrity of the tracker itself
